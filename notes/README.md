# notes/

Personal development-time notes for `vib-mcp-client`. This folder is **only**
for notes, planning, and markdown written while developing.

## Purpose

- Capture planning, ideas, and task breakdowns **before** any code change.
- Keep step/phase logs for every update, fix, or feature.
- Record what was implemented, when, and why.

## Rules

- Write or update a note here **before** starting any update, fix, or feature.
- Every change must have a log entry: what changed, which phase/step, and when.
- Use one markdown file per topic/feature/change, named descriptively
  (e.g. `2026-11-26-add-remove-command.md`).
- Keep notes informal; production-grade documentation belongs in `project/`
  and `docs/`.
- Do not store secrets, tokens, or `.env` values here.

## When to use

- Before implementing anything: draft the plan here first.
- During implementation: append phase/step progress.
- After implementation: confirm what landed and link to the related
  `project/` documentation update.

See `MANIFEST.md` for the list of notes in this folder.
